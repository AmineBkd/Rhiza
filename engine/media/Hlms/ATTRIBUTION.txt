These shader template files (.any / .hlsl) are copied unmodified from the
OGRE-Next project (https://github.com/OGRECave/ogre-next), from its
Samples/Media/Hlms directory, matching the v3.0.0 tag used by vcpkg's
ogre-next port. OGRE-Next is MIT licensed (see its COPYING file).

The vcpkg ogre-next port builds and installs the Hlms *compiled* libraries
(OgreNextHlmsUnlit, OgreNextHlmsPbs, ...) but does not install these *source*
shader-piece files, since HLMS compiles GPU programs at runtime by piecing
these files together. Without them, HlmsUnlit::getDefaultPaths() has nothing
to load and Hlms initialization fails. They are vendored here so the engine
is self-contained and doesn't depend on the vcpkg buildtrees directory
(which may not exist on a clean install / binary-cached build).

Included: Common, Unlit and Pbs, each in all three shading languages Rhiza
targets (HLSL for D3D11/Windows, GLSL for GL3Plus/Linux, Metal for macOS),
plus the language-agnostic .any pieces they share.

The folder layout is not arbitrary - it is exactly what
HlmsUnlit::getDefaultPaths() and HlmsPbs::getDefaultPaths() ask for at
runtime, including Pbs/Any/Main and Pbs/Any/Atmosphere. Renaming or
flattening these directories will break Hlms startup.
